# v3.3.6-rc.3 — WebUI client API-key management (pre-release)

> 2026-10-03 · release candidate

## Added

- The WebUI "Settings" page can generate multiple API keys for different clients, copy a new key, view each key's prefix and creation time, and revoke keys individually.
- The full key is returned only once at creation; the server stores only a SHA-256 hash in `data/api_keys.sqlite3`.
- Legacy `API_KEYS` / `DEEPSEEK_API_KEY` values in `.env` are imported once when the key database is first initialized; afterwards API authentication is managed by the database.
- The service version returned by the admin API is updated to `3.3.6-rc.3`.

## Fixes & verification

- On startup, if no `.env` exists, `start.bat` creates the config file from `.env.example`.
- Added tests for API-key storage, one-time import, the admin endpoints, and `/v1` authentication, and added them to the Python 3.10–3.12 CI unit-test matrix.
- Local verification: 108 pytest items, the smoke test, and the e2e checks pass.
