# v3.3.6-rc.1 — WebUI startup dependency-install fix (pre-release)

> 2026-10-03 · release candidate

## Fixes

- `start.bat` delegates WebUI dependency handling and the build to a dedicated build script.
- Checks for `tsc` and `vite` before building; if dependency install fails or the tools are still missing, it errors out immediately instead of letting a broken `node_modules` cause later startup errors.
- Uses `npm ci` when a `package-lock.json` is present, and on install failure suggests checking the npm registry or proxy connection.
- The GitHub Release workflow creates tags with a pre-release suffix (e.g. `v3.3.6-rc.1`) as pre-releases.

## Verification notes

- Reviewed the batch file's diff format.
- WebUI build not run: in the current environment the npm registry proxy is unreachable and the dependency install fails; this version fixes the error-handling path after such a failure.
