# v3.3.6-rc.4 — unified account-pool configuration (pre-release)

> 2026-10-03 · release candidate

## Changes

- Removed `.env` account fallback loading; accounts are configured only through the WebUI account pool or `data/accounts.json`.
- No longer reads numbered or legacy `DEEPSEEK_TOKEN`, `DEEPSEEK_COOKIES`, `DEEPSEEK_EMAIL` config, and removed the per-account proxy config that existed only to serve env account fallback.
- An empty account pool no longer tries environment-variable credentials; the startup log prompts you to add an account in the WebUI or `data/accounts.json`.
- The WebUI drops the env-account read-only state and source stats; updated `.env.example`, the Chinese and English READMEs, and the maintenance docs.
- The service version returned by the admin API is updated to `3.3.6-rc.4`.

## Verification

- Full pytest suite: 103 items pass.
- WebUI: TypeScript check and Vite production build pass.
